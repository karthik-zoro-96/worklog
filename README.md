# Worklog ⏱

**A brutal, distraction-free timer that forces you to be honest.**

> *Dashboards and analytics apps didn't help—they just gave me charts to stare at instead of doing actual work. So I built a much simpler, more brutal system.*

**[Try it live 🚀](https://karthik-zoro-96.github.io/worklog/)**

---

## How it works

Every 30 minutes, your screen freezes with a full-screen overlay and a 60-second countdown. In that one minute, you are forced to write down exactly what you did in the last 30 minutes.

It sounds intense, but this one habit completely fixes your focus. You know exactly where your time goes, and it's impossible to waste an hour on Twitter when you know the prompt is coming in 15 minutes.

- **Frictionless:** 100% free, no accounts, no sign-ups.
- **Private:** Everything is stored locally in your browser (`localStorage`). No servers, no tracking.
- **Exportable:** Download a clean Markdown file of your entire worklog history at any time.
- **Customizable:** Change the 30-minute interval, the 60-second duration, and the prompt text to whatever fits your workflow.

## Usage

1. Open the app
2. Click **Start Session**
3. Keep the tab pinned in your browser (a soft chime will play when the 30-minute timer hits zero)
4. Be honest!

## Technical Details

Worklog is built as a single, portable HTML file with zero dependencies. It uses standard vanilla Javascript, CSS variables for theming, and embedded SVGs for the countdown rings. 

Feel free to fork this repo and customize it for your own workflow!
